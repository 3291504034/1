# elainabot 插件库

本仓库托管 elainabot 机器人插件。

## 管理娱乐插件

群管理 + 娱乐一体化插件（位于 `plugins/管理娱乐/`）：

- **群管理**：禁言 / 解禁 / 拉黑 / 黑名单 / 撤回 / 违禁词过滤 / 刷屏检测 / 入群验证（数字验证码 + 数学题，t1 按钮确认）/ 入群欢迎
- **积分娱乐**：签到 / 抽奖 / 发红包 / 抢红包 / 红包列表 / 抢劫 / 买反甲 / 我的 / 积分排行
- **休闲娱乐**：塔罗牌 / 运势 / 今日人品 / 投票（t1 按钮选项）/ 摸鱼
- **生活信息**：天气 / 微博热搜 / 王者战力 / 随机壁纸 / 每日早报
- **趣图媒体**：单身狗 / 马内 / 装高手 / 小姐姐视频 / 点歌（t1 按钮选歌直接播放）
- **Web 管理面板**：数据总览 / 用户管理 / 参数配置 / 功能开关 / 群管设置 / 回复文案 / 接口密钥

### 安装

1. 将 `plugins/管理娱乐/` 复制到机器人 `plugins/` 目录
2. 重启机器人（自动加载）
3. 打开机器人 Web 后台 → 管理娱乐面板 → 「密钥」页配置接口密钥

### 密钥配置

插件调用第三方接口，密钥不写死在代码：
- Web 面板「密钥」页填写，或编辑 `data/config.json`：
  ```json
  { "api_keys": { "gulangsc": "你的天迹云apikey" } }
  ```
- 接口文档：https://gulangsc.cn/doc

详见插件内 `README.md`。
