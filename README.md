## 🚀 管理娱乐插件 · 全栈群机器人引擎

一个插件，完整承载 **群秩序治理 + 积分经济体 + 内容消费** 三大场景。不是玩具，是生产级落地的群机器人解决方案。

### 🛡 群管中枢 —— 秩序自动化

| 能力 | 说明 |
|------|------|
| **入群验证多模态** | 数字验证码 / 数学题 双模式，**回调按钮一键确认**，通过后自动撤回验证消息并融合欢迎语 |
| **智能禁言体系** | 违规阶梯惩罚、刷屏自动检测、超时自动解封 |
| **黑名单治理** | 拉黑 / 解除 / 列表查询，构建群内信用档案 |
| **消息撤回** | 三层消息定位（引用/显式ID/自动），精准回收不当言论 |
| **违禁词过滤** | 实时拦截 + 违规计数，出群管面板可维护 |

### 💰 积分经济体 —— 群内活力引擎

签到 / 抽奖 / 拼手气红包 / 抢劫 / 反甲护盾 / 个人资产 / 全群排行 —— **一整套积分闭环**，让群聊活跃度肉眼可见地增长。防滥用内建：每日限次、冷却惩罚、反甲反弹。

### 🎲 休闲娱乐 —— 24 小时在线

塔罗牌占卜 · 每日运势 · 今日人品 · 群投票 · 摸鱼日历 —— 每一条回复都是**原生 Markdown 富文本**（头像+@+重点加粗+卡片排版）。

### 🎵 内容服务 —— 接口层容错设计

天气 / 微博热搜 / 王者战力 / 壁纸 / 早报 / 小姐姐视频 / 狗头配图（单身狗·马内·装高手）**/ 点歌直播**。

> 全部外部接口调用内置 **三重自动重试 + 连接异常自愈**（TLS EOF 自动重建连接池），恶劣网络下依然稳定。

### 🎛 交互范式 —— 全回调式按钮

深度集成 QQ 官方 `INTERACTION_CREATE` 交互事件：
- **点歌选歌**：搜索出结果 → 歌曲按钮 → **点击即播放**，零输入
- **群投票**：选项按钮直投，**一人一票不可刷**
- **入群验证**：答案按钮确认，替代繁琐打码
- 每个回调响应自动携带 **操作者头像 + @ 识别**，多人并发不混淆

### 🖥 内置 Web 管理面板

数据总览 · 用户管理 · 积分调控 · 参数配置 · 功能开关 · 群管设置 · 回复文案 · **接口密钥可视化配置**（密钥不入代码，安全可分发）。

### 🔀 按群隔离 —— 多群并行不串台

**数据层**：积分 / 签到 / 红包 / 黑名单 / 投票 / 禁言 / 刷屏记录全部按群分桶（`{gid: ...}`），A 群的经济体与 B 群完全独立。

**配置层**：`groups` 群覆盖结构（**群覆盖 > 全局默认**）——

- 功能开关按群：群A 关签到、群B 开，互不影响
- 数值参数按群：签到范围 / 抽奖概率 / 红包限制 / 惩罚阶梯独立调整
- 违禁词 / 欢迎语 / 入群验证按群独立（群A 数学验证、群B 数字验证）
- Web 面板群选择器：选"全部群"编辑全局默认，选群只编辑该群，未覆盖项回落全局

存量群零影响、无需迁移。

## 📦 快速开始

```bash
# 1. 将插件目录复制到机器人 plugins/ 下
cp -r plugins/管理娱乐 /path/to/elainabot/plugins/

# 2. 重启机器人，自动加载
# 3. 打开 Web 后台 → 管理娱乐面板 →「密钥」页配置接口密钥
```

### 🔑 密钥配置（零代码）

```json
{ "api_keys": { "gulangsc": "你的天迹云 apikey" } }
```

接口文档：`https://gulangsc.cn/doc` —— 面板填写 / 配置文件写入，二选一，即时生效。

## 🏗️ 架构亮点

- **数据持久化**：JSON 文件存储，零数据库依赖，即拷即用
- **无状态设计**：重启不丢数据，热插拔
- **安全默认**：密钥剥离代码、交互鉴权（非本人按钮静默拒绝）、管理员操作 only_admin 隔离
- **高可用**：接口故障时优雅降级提示，不阻塞主流程
