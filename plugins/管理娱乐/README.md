# 管理娱乐插件

QQ 机器人「管理娱乐」插件：群管理（禁言/黑名单/违禁词/入群验证/撤回）+ 娱乐（签到/抽奖/红包/抢劫/塔罗牌/点歌/天气等）+ Web 后台管理面板。

## 目录结构

```
管理娱乐/
├── main.py            # 插件入口（注册命令/拦截器/Web页面）
├── app/
│   ├── commands.py    # 群命令处理器
│   ├── monitor.py     # 消息拦截（入群验证/违禁词/黑名单/刷屏/撤回）
│   └── webpanel.py    # Web 管理面板 API
├── mod/
│   ├── api.py         # 外部接口调用（天气/作图/点歌等）
│   ├── config.py      # 全局配置 + 按群覆盖（群配置 > 全局默认）
│   ├── db.py          # 数据持久化（JSON 文件，运行数据按群隔离）
│   ├── points.py      # 积分系统
│   ├── redpack.py     # 红包
│   ├── tarot.py       # 塔罗牌/运势/今日人品/投票
│   ├── mute.py        # 禁言/撤回/违规惩罚
│   └── reply.py       # 回复工具（md/卡片/头像@）
├── web/               # Web 管理面板前端
└── data/              # 运行数据（不入库，见 .gitignore）
```

## 按群隔离

每个群都是独立的"平行宇宙"，数据与配置双层隔离：

### 数据隔离（运行数据按群分桶）

| 数据 | 隔离方式 |
|------|---------|
| 积分 / 签到 / 连签 | `pts:{gid}` / `sign:{gid}` / `streak:{gid}` |
| 红包 / 黑名单 / 投票 / 禁言 / 违规 | `{gid: {...}}` 分层存储 |
| 刷屏记录 | 内存按群计时 |

→ 用户在 A 群赚的积分、被拉黑的记录，与 B 群完全独立。

### 配置隔离（群覆盖 > 全局默认）

`data/config.json` 支持 `groups` 群覆盖结构：

```json
{
  "sign_lo": 1,
  "sign_hi": 150,
  "features": {"sign": true, "lottery": true},
  "groups": {
    "群A-ID": {"sign_lo": 50, "features": {"sign": false}},
    "群B-ID": {"sign_hi": 300}
  }
}
```

- **功能开关**：群A 关签到、群B 开，互不影响
- **数值参数**：签到范围 / 抽奖概率 / 红包限制 / 阶梯惩罚等均可按群调整
- **违禁词 / 欢迎语 / 入群验证**：按群独立存储（`{gid: 值}` + `_global` 兜底），群A 数学验证、群B 数字验证都行
- **回复文案**：`get_reply(name, gid)` 按群取文案

### Web 面板操作

顶部**群选择器**切换编辑范围：
- **全部群** = 编辑全局默认
- **某个群** = 只编辑该群（未覆盖项显示全局默认，保存只写该群）

> 未配置覆盖的群自动使用全局默认，存量群零影响、无需迁移。

## 接口与密钥配置

本插件调用第三方开放接口，**密钥不再硬编码在代码中**，由你自行填入：

### 需要配置的密钥

| 密钥字段 | 用途 | 接口文档 | 获取位置 |
|---------|------|---------|---------|
| `api_keys.gulangsc` | 装高手/单身狗/马内/小姐姐 等天迹云作图接口 | https://gulangsc.cn/doc | 登录 https://gulangsc.cn → 个人中心 → 复制 apikey |

### 配置方式（二选一）

**方式一：Web 管理面板（推荐）**
1. 打开机器人 Web 管理后台 → 「管理娱乐」面板
2. 左侧导航 → 「密钥」
3. 每个密钥输入框旁有说明（用途/文档/获取位置）
4. 粘贴你的密钥 → 保存

**方式二：直接编辑配置文件**
编辑 `data/config.json`，添加字段：

```json
{
  "api_keys": {
    "gulangsc": "你的天迹云apikey"
  }
}
```

保存后重启机器人生效（或通过面板保存实时生效）。

> 未配置密钥时，相关功能会请求失败并提示，配置后立即恢复，无需改代码。

### 无需密钥的接口

- 天气 / 热搜 / 战力 / 壁纸：`https://gulangsc.cn/API`（免费接口，无需 key）
- 早报：`https://uapis.cn/api/v1/daily/news-image`
- 点歌：`https://a.aa.cab/qq.music`

## 使用

- 命令前需 @机器人 或直接发（取决于框架配置）
- 全部命令回复为 markdown 消息，按钮均使用 type=1 回调式（点击直接生效）
- Web 面板：`/{bot_web_prefix}/superadmin`（群管/娱乐/密钥管理）

## 数据文件

`data/` 下为运行数据（users/config/redpacks/votes 等 JSON），**不纳入版本库**，请勿提交。

## 开发注意事项

- 接口调用（`mod/api.py`）已内置重试 + 连接异常重建（TLS EOF 自动恢复）
- 按钮回调 data 格式：`jv:{uid}:{ans}`（入群验证）、`mg:{uid}:{idx}`（点歌）、`vt:{vid}:{idx}`（投票），三者在正则上完全隔离
- 交互回调（INTERACTION_CREATE）回复 `event.reply` 会发到群，已加「头像+@操作者」前缀便于多人区分
